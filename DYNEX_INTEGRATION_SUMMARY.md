## 🛠️ **API Integration**

### **Quantum Computing API Endpoints**

#### **POST /api/quantum/dynex**
Execute quantum operations on Dynex platform

**Request Body:**
```json
{
  "operation": "circuit|qubo|optimization|ml",
  "data": {
    // Operation-specific data
  },
  "options": {
    "shots": 1000,
    "num_reads": 1000,
    "annealing_time": 1000,
    "network": "mainnet|testnet"
  }
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "result": "...",
    "processing_time": 1500,
    "cost": 0.05,
    "method": "quantum",
    "platform": "dynex"
  },
  "usage": {
    "daily_usage": 45,
    "quota": 1000,
    "remaining": 955
  }
}
```

### **Supported Operations**

#### **1. Quantum Circuit Execution**
```typescript
{
  "operation": "circuit",
  "data": {
    "qubits": 4,
    "gates": [
      {"type": "h", "qubits": [0]},
      {"type": "cx", "qubits": [0, 1]},
      {"type": "measure", "qubits": [0, 1]}
    ]
  }
}
```

#### **2. QUBO Problem Solving**
```typescript
{
  "operation": "qubo",
  "data": {
    "matrix": [[-1, 2], [2, -1]],
    "linear_terms": [0, 0],
    "constant": 0
  }
}
```

#### **3. Optimization Problem Solving**
```typescript
{
  "operation": "optimization",
  "data": {
    "type": "tsp",
    "data": {
      "cities": ["A", "B", "C", "D"],
      "distances": [[0, 10, 15, 20], [10, 0, 35, 25], [15, 35, 0, 30], [20, 25, 30, 0]]
    }
  }
}
```

#### **4. Machine Learning**
```typescript
{
  "operation": "ml",
  "data": {
    "type": "classification",
    "X": [[1, 2, 3], [4, 5, 6]],
    "y": [0, 1],
    "parameters": {"max_features": 10}
  }
}
```

### **Quick Start Example**
```python
import metisai_quantum as mq
from metisai_quantum.dynex import DynexQuantumProcessor

# Initialize MetisAI Quantum Processor
quantum_processor = DynexQuantumProcessor(
    api_key="your_metisai_api_key",
    network="mainnet"
)

# Basic quantum computation
result = quantum_processor.compute_quantum_circuit(
    circuit=your_quantum_circuit,
    shots=1000
)

print(f"Quantum computation result: {result}")
```
